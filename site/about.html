🎉 What is Champ Words?

Champ Words is a real-time multiplayer word guessing game where the fastest mind wins. One word drops, the clock starts, and a room full of rivals races to crack it first. It's part word puzzle, part speed duel, and entirely addictive.

The game was built for players who love the rush of beating the clock — with leaderboards that reward both consistency (all-time legends) and daily hustle (today's race).

🚀 The Arena

  • 6300+ word dictionary across 13+ themed categories — travel, sports, food, people, music, nature and more.
  • Up to 8 players per room with private room codes and a public active arena.
  • Live voice chat so you can coordinate (or trash-talk) in real time.
  • Power-up economy — hints, timer freezes and winner challenges add strategy to every round.
  • Streaks, XP, levels and achievements keep every session rewarding.

🛠️ Under the Hood

Champ Words runs on a real-time Node.js + Socket.IO game server with a React front end. This website is a clean, static Bootstrap build — no WordPress, no database. The gameplay streams in live from the game engine, and the leaderboards read straight from the arena's API.
