# Champ-Words

Initial scaffold for the multiplayer guessing word game server.

This repository was created by an automated assistant. It contains a TypeScript + Socket.IO prototype server and a tiny demo client so friends can play a Wordle-like game together.

Files include:
- package.json
- tsconfig.json
- src/server.ts
- src/game.ts
- src/words.txt
- public/index.html

Run locally:
- npm install
- npm run dev
